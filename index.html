This window can’t run the app.
Why. iPhones refuse to run scripts in a file opened from storage — a preview sheet, the Files app, an email attachment. The page draws and then stops. Nothing on the phone gets around it.
The fix. Guzo needs a web address. Put this file on any free static host — Cloudflare Pages, GitHub Pages, Netlify — and open the link it gives you.
Then. In Safari, tap Share → Add to Home Screen. It opens full screen with its own icon and keeps your training on the device.
One upload, once. After that it updates by replacing a single file.
